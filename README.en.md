# LectoForge · Local-first Learning Workbench

**A local-first macOS workbench connecting capture, organization, review and output in a daily learning workflow.**

[Installation](README.md#安装与使用) · [Screenshots](README.md#界面一览) · [Architecture](docs/ARCHITECTURE.md)

- Cornell notes, SM-2 spaced repetition, memory palace and Feynman practice.
- Local Markdown library, AI assistant and RAG answers with sources.
- Learning data is stored locally; cloud AI requests send relevant questions and retrieved excerpts to the configured provider.

**Technology / topics:** Tauri 2 · Rust · Vue 3 · TypeScript · Fastify · SQLite
