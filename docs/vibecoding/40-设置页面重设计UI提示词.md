# 设置页面重设计 UI 提示词

> 参考 Cherry Studio 三栏布局模式，重设计 LectoForge 设置页面。
> 保持与项目 `--kb-*` 设计令牌一致，不脱离整体风格。
> 使用前请先阅读 `00-总览与设计规范.md`。

---

## 1. 设计目标

将当前单栏卡片滚动式设置页，重构为**三栏导航式布局**，参考 Cherry Studio 的设计模式：

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [窗口控制]  [Logo]  ...  [搜索⌘K] [番茄钟] [设置] [更新] [计时胶囊]      │
├──────────┬──────────────────┬────────────────────────────────────────────┤
│ 左侧导航  │  中间子项列表     │  右侧设置详情                               │
│          │                  │                                            │
│ 🔧 通用   │  ┌────────────┐  │  ┌─ 通用设置 ──────────────────────────┐  │
│  📁 数据  │  │ 知识库路径  │  │  │  语言              [中文▼]          │  │
│  🤖 AI    │  │ 备份设置    │  │  │  主题模式          [浅色][深色][系统]│  │
│  🎨 外观  │  │ 导入导出    │  │  │  主题色  ● ● ● ● ● ● ●  [🎨]       │  │
│ 🔔 通知   │  └────────────┘  │  │  字号缩放          [小][标准][大]   │  │
│ ⌨️ 快捷键 │                  │  │  紧凑模式          [开/关]          │  │
│ 🔗 同步   │                  │  └────────────────────────────────────┘  │
│ ℹ️ 关于   │                  │                                            │
└──────────┴──────────────────┴────────────────────────────────────────────┘
```

### 1.1 设计模式分析（来自 Cherry Studio 截图）

**三栏布局核心特征**：

| 区域 | 宽度 | 内容 | 交互 |
|------|------|------|------|
| 左侧导航 | 200px | 图标+文字分组导航项 | 点击切换右侧内容，激活态高亮 |
| 中间子项 | 240px | 子分类列表或二级导航 | 可选的二级分组 |
| 右侧详情 | 自适应 | 设置卡片分组 | 行级设置：标签左+控件右 |

**关键 UI 模式**：
1. **行级设置**：每行左侧标签、右侧控件（开关/下拉/输入/按键绑定），用分隔线或卡片分组
2. **卡片分组**：相关设置用 `.kb-card` 包裹，卡片内用分隔线或 `kb-divider` 分行
3. **开关样式**：自定义 toggle（`.lf-switch` 风格），非原生 checkbox
4. **分段控件**：主题切换用 `.kb-filter-group` + `.kb-filter-btn`
5. **颜色选择器**：圆点色标，当前选中带边框高亮
6. **按键绑定**：显示修饰键组合（如 `⌥ ⇧ N`），右侧有重置按钮
7. **状态徽章**：连接状态用圆点+文字（已连接/未配置）

### 1.2 与项目现有样式对齐

| Cherry 模式 | 对应项目令牌/类 |
|-------------|----------------|
| 左侧导航激活态 | `var(--kb-primary)` 背景 + 主色文字 |
| 卡片分组 | `.kb-card` + `.kb-card-hover` |
| 行分隔线 | `var(--kb-border)` |
| 开关 | 复用现有 `.lf-switch` 或新建 `--kb-switch-*` |
| 分段控件 | `.kb-filter-group` + `.kb-filter-btn` |
| 颜色圆点 | 自定义 `.kb-color-dot` |
| 按键显示 | `.kb-kbd` 现有类 |
| 图标 | `<Icon name="lucide名">` |

### 交互细节

- 左侧导航宽度固定 200px，右侧自适应
- 导航项：`Icon`(16px) + 文字 + 可选角标
- 激活态：左侧 3px 主色竖条 + 主色文字 + 主色 10% 背景色
- 悬停态：背景色微变（`var(--kb-hover-bg)`）
- 分组标题：`.kb-caption` 字号 + 灰色 + 大写字母间距
- 角标：小圆点徽章（warning=橙/danger=红/success=绿）
- 导航项用 `<router-link>` 或 `@click` + `activeKey` 状态驱动右侧面板切换

### 复用类

- `.kb-region-sidebar` 作为左侧背景
- 导航项：`.sidebar-nav-item`（已有或新建）
- 分组标题：`.sidebar-group-label`（已有或新建）

### 设置行组件模式

```html
<div class="kb-setting-row">
  <div class="kb-setting-label">
    <span>语言</span>
    <span class="kb-setting-desc">界面显示语言</span>
  </div>
  <div class="kb-setting-control">
    <!-- 控件：dropdown / toggle / input / keybinding / color-dot -->
  </div>
</div>
```

### 控件类型

| 类型 | 组件/样式 | 用途 |
|------|----------|------|
| 开关 Toggle | `.kb-switch`（自定义，复用现有 lf-switch 风格） | 布尔设置 |
| 下拉选择 | `.kb-select` | 枚举选择 |
| 分段控件 | `.kb-filter-group` + `.kb-filter-btn` | 2-4 个互斥选项 |
| 输入框 | `.kb-input` | 文本/URL/Key |
| 数字输入 | `.kb-input type=number` | 数值 |
| 滑块 | `<input type=range>` + 数值显示 | 温度/缩放等 |
| 颜色圆点 | `.kb-color-dot` | 主题色选择 |
| 按键绑定 | `.kb-keybinding` 容器 | 快捷键显示+重新绑定 |
| 按钮 | `.kb-btn` / `.kb-btn-primary` | 测试/保存等操作 |
| 状态徽章 | `.kb-status-badge` | 连接状态显示 |

- 绑定区域显示修饰键组合（`⌥ ⇧ N`），用 `.kb-kbd` 风格包裹
- 右侧两个按钮：⌫ = 清除绑定 / 🔒 = 锁定（防误改）

- 状态列：● 绿色=已注册 / ⚠ 橙色=冲突 / ○ 灰色=未注册
