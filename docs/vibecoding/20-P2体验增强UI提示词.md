## F6 · 主题与外观自定义

### 功能目标
开放主题色、字号缩放、紧凑模式三项用户级外观自定义。

### 涉及文件
- 修改：`src-ui/src/style.css`（令牌改造）、`src-ui/src/store/app-store.ts`（appearance 字段）
- 新增：`src-ui/src/views/Settings/AppearanceSection.vue`

### UI 界面设计

**位置**：设置中心 `/settings` 新增「外观」分区（`AppearanceSection.vue`）

```
┌─────────────────────────────────────────────────┐
│ 外观                                             │
│ ─────────────────────────────────────────────── │
│                                                   │
│ 主题模式                                          │
│  [☀ 浅色]  [🌙 深色]  [💻 跟随系统]               │
│                                                   │
│ ───────────────────────────────────────────────  │
│ 主题色                                            │
│  ●  ●  ●  ●  ●  ●  ●  [🎨 自定义]                │
│  蓝  绿  紫  橙  红  青  粉                       │
│  (当前选中：蓝 ●)                                 │
│                                                   │
│ ───────────────────────────────────────────────  │
│ 字号缩放                                          │
│  [小]  [标准]  [大]  [特大]                       │
│  87.5%  100%  112.5%  125%                        │
│                                                   │
│  预览：                                            │
│  ┌─────────────────────────────────────────┐    │

│  └─────────────────────────────────────────┘    │
│                                                   │
│ ───────────────────────────────────────────────  │
│ 紧凑模式                                          │
│  [标准]  [紧凑]                                   │
│  紧凑模式压缩间距与组件高度，列表密度提升约 30%    │
└─────────────────────────────────────────────────┘
```

**交互细节**：
- 主题模式：三选一按钮（`.kb-filter-group` + `.kb-filter-btn`），立即生效
- 主题色：7 个预设色圆点 + 自定义取色器，点击立即注入 `document.documentElement.style.setProperty('--kb-primary', color)`
- 字号缩放：四档单选，设置 `--kb-font-scale` 变量，所有 `--kb-fs-*` 改为 `calc(基础值 * var(--kb-font-scale))`
- 紧凑模式：`<html data-density="compact">`，全局压缩 `--kb-space-*` 与组件高度
- 预览区实时反映当前选择
- 三项设置进 `app-store.ts` 的 `settings.appearance`，持久化并首启应用

### 验收标准
- [ ] 切换主题色后，全站按钮/链接/进度条/选中态同步变化
- [ ] 字号缩放四档，切换后布局不错乱
- [ ] 紧凑模式下，列表密度提升约 30%，可读性不丢

## F7 · 统一标签体系

### 功能目标
建立统一标签主表 + 多态关联表，实现跨模块按标签聚合检索。

### 涉及文件
- 修改：`src-api/src/db/schema.ts`（新增两表）、`src-api/src/db/index.ts`（建表 + backfill）
- 新增：`src-api/src/services/tagService.ts`、`src-api/src/routes/tags.ts`、`src-api/src/controllers/tagController.ts`
- 修改：`src-api/src/services/searchService.ts`（tag 筛选）
- 修改前端各列表页：加标签筛选侧栏

### UI 界面设计

**位置 1**：命令面板 `/api/tags` 标签云面板

**位置 2**：各列表页（收集箱/笔记/任务）左侧新增标签筛选侧栏

```
┌─ 标签 ──────────┐
│ # Java       23 │  ← 点击筛选，高亮选中
│ # 并发       12 │
│ # Redis       8 │
│ # 算法        6 │
│ # 面试        5 │
│ + 新建标签      │
└─────────────────┘
```

**位置 3**：新建内容时的标签输入（自动补全）

```
标签：[Java] [并发] [输入...]  ×
       ┌──────────────┐
       │ # 并发        │  ← 自动补全下拉
       │ # 并行        │
       └──────────────┘
```

**交互细节**：
- 标签侧栏：`.kb-region-sidebar` 背景，标签项 `.kb-card-hover` 悬停
- 点击标签 → 列表筛选显示该标签下所有实体（跨模块）
- 标签输入：输入时自动补全已有标签（`.kb-dropdown-panel`）
- 新建标签：输入新名 → 回车创建（默认随机色）
- 标签云：字号/颜色深浅按使用频率区分

### 后端接口设计

```
GET    /api/tags              → 标签列表 + 各标签实体计数（按类型分组）
POST   /api/tags              → 新建标签 { name, color }
PUT    /api/tags/:id          → 更新标签
DELETE /api/tags/:id          → 删除标签（解绑所有关联）
GET    /api/tags/:id/items    → 该标签下所有实体
POST   /api/tags/bind         → 绑定 { tagId, entityType, entityId }
DELETE /api/tags/bind         → 解绑
```

### 数据层设计

```sql
wb_tag (id, name, color, user_id, created_at)
wb_tag_binding (id, tag_id, entity_type, entity_id, user_id, created_at)
```

### 验收标准
- [ ] `/api/tags` 返回标签云 + 计数
- [ ] 点击某标签，跨收集箱/笔记/任务展示所有相关项
- [ ] 新建内容时输入标签有自动补全

## F8 · 跨模块深度联动

### 功能目标
打通番茄钟↔任务、笔记↔任务、日历↔任务/番茄钟、收集箱↔任务的闭环。

### 涉及文件
- 修改：`src-api/src/db/schema.ts`（`wb_pomodoro_log` 加 `taskId`、`wb_calendar_event` 加 `taskId`）
- 修改：`pomodoroService.ts`、`taskService.ts`、`calendarService.ts`、`inboxService.ts`
- 修改：`src-ui/src/store/pomodoro-store.ts`、`task-store.ts`
- 修改：笔记编辑器（`- [ ]` 解析）、收集箱沉淀菜单

### UI 界面设计

**1. 番茄钟 ↔ 任务**：

番茄钟启动弹窗（选择关联任务）：
```
┌─ 开始专注 ───────────────────────┐
│  关联任务（可选）                  │
│  ┌──────────────────────────┐   │
│  │ ☐ 不关联                  │   │
│  │ ☑ 完成 Java 并发笔记       │   │
│  │ ☐ 复习 Redis 闪卡         │   │
│  │ ☐ 写周报                  │   │
│  └──────────────────────────┘   │
│                                   │
│  专注时长：25 分钟                 │
│              [取消]  [开始专注]    │
└───────────────────────────────────┘
```

任务详情显示专注累计：
```
┌─ 任务详情 ───────────────────────┐
│ 完成 Java 并发笔记                 │
│ ...                               │
│ 📊 累计专注：3 个番茄 · 75 分钟    │  ← 新增
└───────────────────────────────────┘
```

**2. 笔记 ↔ 任务**：

笔记编辑器中 `- [ ]` 语法渲染为可勾选项：
```

- [x] 复习并发章节        ← 勾选后同步到任务清单
- [ ] 写实践代码          ← 未勾选
- [ ] 整理笔记            ← 未勾选
```

**3. 收集箱 ↔ 任务**：

收集项沉淀菜单新增「转为任务」：
```
┌─ 沉淀到 ──────────┐
│ 📝 转为笔记        │
│ 🏛 转为宫殿位点    │
│ 📖 转为故事        │
│ ✅ 转为任务  ← 新增 │
└────────────────────┘
```

转为任务时弹出快速任务创建框（标题预填收集项内容）。

**4. 日历 ↔ 任务/番茄钟**：

日历事件可关联任务，番茄钟专注在日历生成色块：
```
日历周视图：
┌─────────────────────────────────┐
│ 10:00 ┌─────────────┐           │
│       │ 团队周会     │           │
│ 10:30 └─────────────┘           │
│ 11:00 ┌─────────────┐           │
│       │ 🍅 专注     │ ← 番茄色块│
│ 11:25 └─────────────┘           │
└─────────────────────────────────┘
```

### 验收标准
- [ ] 番茄钟启动时可选任务，完成后任务详情累加专注时长
