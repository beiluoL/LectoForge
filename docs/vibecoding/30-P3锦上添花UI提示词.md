## F11 · OCR 与截图能力增强

### 功能目标
截图归档、标注增强、PDF OCR、云端 OCR 可选。

### 涉及文件
- 修改：`src-ui/src/lib/screenshot.ts`、`src-ui/src/components/media/OcrModal.vue`
- 新增：`src-ui/src/components/media/ScreenshotAnnotator.vue`
- 修改：`src-api/src/controllers/qaBankController.ts`（PDF OCR）

### UI 界面设计

**1. 截图归档**：

截图完成后 `OcrModal.vue` 增加保存选项：
```
┌─ 截图 OCR ────────────────────────────┐
│                                          │
│  ┌────────────────────────────────┐    │
│  │                                  │    │
│  │       [截图预览区域]              │    │
│  │                                  │    │
│  └────────────────────────────────┘    │
│                                          │
│  识别结果：                              │
│  ┌────────────────────────────────┐    │
│  │ Java ConcurrentHashMap 分段锁    │    │
│  │ ...                              │    │
│  └────────────────────────────────┘    │
│                                          │
│  [✏ 标注]  [💾 保存图片到收集箱]         │  ← 新增
│  [复制文本]  [沉淀到笔记]  [关闭]        │
└──────────────────────────────────────────┘
```

**2. 标注画布** `ScreenshotAnnotator.vue`：

点击「标注」进入标注模式：
```
┌─ 截图标注 ──────────────────────────────┐
│  [箭头] [框选] [文字] [马赛克] [撤销]    │  ← 工具栏
│ ─────────────────────────────────────── │
│                                          │
│  ┌────────────────────────────────┐    │
│  │                                  │    │
│  │    ┌──→  ← 标注箭头              │    │
│  │    │                            │    │
│  │    ████ ← 马赛克                │    │
│  │                                  │    │
│  └────────────────────────────────┘    │
│                                          │
│  [取消]                  [完成标注]      │
└──────────────────────────────────────────┘
```

标注完成后可：
- 保存标注后的图片到收集箱
- 对标注后图片重新 OCR
- 复制到剪贴板

**3. PDF OCR**：

题库导入 PDF 时增加 OCR 选项：
```
┌─ 导入 PDF 题库 ────────────────────────┐
│  文件：java_interview.pdf              │

│    （识别图片中的文字后再解析）          │

│                                          │
│              [取消]  [开始导入]          │

```

**4. 云端 OCR 可选**（设置中心）：

```
┌─ OCR 设置 ─────────────────────────────┐
│  引擎：[● 离线 tesseract.js]           │
│        [○ 腾讯云 OCR]                  │
│        [○ 百度云 OCR]                  │
│                                          │
│  云端密钥（选择云端引擎时填写）：        │
│  SecretId:  [________________]          │
│  SecretKey: [________________]          │
│                                          │
│  [测试 OCR]                             │
└──────────────────────────────────────────┘
```

**交互细节**：
- 标注工具栏用 `.kb-filter-group` + `.kb-filter-btn` 风格
- 标注画布用 Canvas 实现，颜色用 `var(--kb-primary)` + `var(--kb-destructive)`
- 马赛克用像素化处理
- OCR 进度用进度条
- 云端 OCR 复用 ai-config 模式（密钥只在后端）

### 验收标准
- [ ] 截图后可选择「保存图片到收集箱」
- [ ] 标注画布支持箭头/马赛克/文字
- [ ] 扫描型 PDF 导入题库时文字可识别

## F12 · 多语言 i18n

### 功能目标
支持中/英双语，为可能的出海做准备。

### 涉及文件
- 新增：`src-ui/src/locales/zh-CN.json`、`src-ui/src/locales/en-US.json`、`src-ui/src/i18n.ts`
- 修改：全项目所有硬编码中文（前端 view 与 store）
- 修改：`src-tauri/src/lib.rs`（托盘菜单文案动态化）、`src-tauri/src/tray.rs`
- 修改：`src-ui/src/store/app-store.ts`（`locale` 字段）

### UI 界面设计

**位置**：设置中心 `/settings` 新增「语言」分区

```
┌─────────────────────────────────────────┐
│ 语言 / Language                          │
│ ─────────────────────────────────────── │
│                                          │
│  [🇨🇳 简体中文]  [🇺🇸 English]          │
│                                          │
│  首启按系统语言自动选择                   │
└──────────────────────────────────────────┘
```

**交互细节**：
- 语言切换：两选一按钮（`.kb-filter-btn`），立即生效
- 切换后全站文案同步更新（vue-i18n 响应式）
- 首启按系统语言探测（`navigator.language`）
- 语言选择持久化到 `app-store.ts` 的 `locale` 字段
- 托盘菜单文案通过前端 emit 动态设置

**文案抽取范围**：
- 所有 `.vue` 文件中的硬编码中文 → `{{ $t('key') }}`
- store 中的文案常量（如 `PHASE_LABEL`）→ i18n key
- Rust 侧托盘菜单 → 前端动态设置
- 通知文案 → 经 i18n

**i18n 文件结构**：
```json
// zh-CN.json
{
  "nav": {
    "inbox": "收集箱",
    "notes": "笔记",
    "library": "文档库"
  },
  "common": {
    "save": "保存",
    "cancel": "取消",
    "delete": "删除",
    "confirm": "确认"
  },
  "pomodoro": {
    "focus": "专注",
    "shortBreak": "短休",
    "longBreak": "长休"
  }
}
```

### 验收标准
- [ ] 切换语言后全站文案同步
- [ ] 托盘菜单/通知文案同步
- [ ] 首启按系统语言自动选择

## 附录：优先级排期建议

| 优先级 | 功能 | 建议排期理由 |
|--------|------|-------------|
| **P1** | F1-F5 | 桌面效率工具核心期望，缺失显著降低使用意愿 |
| **P2** | F6-F10 | 体验增强，P1 完成后按用户反馈排期 |
| **P3** | F11 | 成本低可穿插做 |
| **P3** | F12 | 需结合产品出海定位决策 |

### 与既有 P4 候选的关系

- 「流式输出」→ F5
- 「语义检索进文档库」→ F10
- 「错题讲解」→ F5 / F9 子项（基于 `wb_review_log` 生成错题解析）
- 「多 embedding 批量重建」→ F10 工程依赖
- 「Keychain 加固」→ F1 安全增强配套
