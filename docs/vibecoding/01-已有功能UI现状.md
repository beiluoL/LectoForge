# 已有功能 UI 现状（开发参考）

> 本文件整理各模块**当前已实现的 UI 界面**，作为新增功能时的视觉一致性参考。
> 新功能必须复用既有布局模式与组件类，保持风格统一。

---

## 1. 核心学习闭环（六模块）

### 1.1 收集箱 `/inbox`

**布局**：左右双栏
- **左栏**：收集项列表（`InboxList.vue`），每项显示内容摘要 + 来源图标 + 时间 + 状态标签（待处理/已沉淀）
- **右栏**：快速输入区（`QuickCapture.vue`），顶部多 Tab 切换输入方式

**输入方式**（Tab 切换）：
- 极速文本输入（回车入库）
- 网页剪藏（粘贴 URL）
- 语音上传（`useVoiceRecorder` + Whisper STT 转写）
- 附件上传（图片/PDF，走 `/api/inbox/upload/asset`）
- 截图 OCR（`captureScreenshot()` + `OcrModal.vue`）

**交互**：
- 列表项点击 → 展开详情 + 沉淀菜单（转笔记/宫殿/故事）
- 去重检测：输入时实时检测相似内容并提示
- 顶栏角标显示待处理数（`pendingCaptures`）

**组件**：`InboxList.vue` / `QuickCapture.vue` / `OcrModal.vue`

---

### 1.2 康奈尔笔记 `/workbench/notes`

**列表页**：卡片网格布局
- 顶部筛选栏：掌握度筛选 + 标签云 + 搜索
- 笔记卡片：标题 + 摘要 + 标签 + 掌握度进度条 + 更新时间
- `.kb-card-hover` 悬停抬升

**编辑页** `/workbench/notes/:id`：三栏布局
- **左栏（线索列）**：关键词 / 问题提示
- **中栏（笔记列）**：主体内容，支持 Markdown
- **右栏（总结列）**：归纳总结
- 顶部工具栏：划词工具栏 + 自动保存指示 + PDF 导出
- 双链反链：`[[笔记名]]` 语法，右侧显示反链列表

**交互**：自动保存（防抖）、掌握度手动标记

### 1.3 间隔重复 `/review`

**复习驾驶舱** `/workbench/review`：

- `ReviewHeatmap.vue`：年度热力图（GitHub contribution 风格）

**传统卡组** `/workbench/review/card-list`：`wb_review_card` 表的卡组管理

### 1.4 记忆宫殿 `/workbench/palace`

**首页** `PalaceHome.vue`：宫殿卡片列表（每个宫殿显示位点数 + 熟练度）
**编辑页** `/workbench/palace/:id`：

### 1.5 主动回忆 `/workbench/recall`

**三轮闭卷默写流程**：
1. 选择笔记 → 显示线索（关键词）
2. 第一轮：凭记忆默写 → 提交
3. 第二轮：对照原文修正 → 提交
4. 第三轮：提炼升华 → 提交

**布局**：单栏流程式，顶部进度指示（1/3 → 2/3 → 3/3）

## 5. 设计模式总结

### 5.1 页面布局模式

| 模式 | 适用场景 | 特征 |
|------|----------|------|
| `fullscreen` | 大多数页面 | 铺满宽度 + 原生滚动（px-4 py-6 内边距） |
| `fill` | 任务/AI对话/日历/流程图 | 铺满整屏 + 内部自管滚动，去除内边距 |
| `standalone` | 引导/设置 | 全屏无顶栏 |

### 5.2 常见组件模式

- **卡片网格**：`grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4` + `.kb-card-hover`
- **左右双栏**：`flex` + 左列表右详情
- **三栏**：文档库式 左树/中编辑/右大纲
- **抽屉**：右侧滑出 `Drawer` 组件
- **模态框**：居中弹窗 + 遮罩
- **Tab 切换**：`.kb-filter-group` + `.kb-filter-btn`
- **空状态**：`.kb-h3` 标题 + 说明 + 主按钮

### 5.3 数据流模式

- **列表页**：onMounted 拉取 → store 缓存 → 渲染
- **乐观更新**：先改 UI → 调 API → 失败回滚 + toast
- **自动保存**：防抖 1-2s → 调 API → 状态指示器
- **流式**：`EventSource` / `fetch + ReadableStream` → 逐字渲染
