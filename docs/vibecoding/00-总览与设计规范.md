# LectoForge 桌面端 · vibecoding 总览与设计规范

> 本文件是所有 vibecoding 提示词的**基础参考**。每次开发前先把本文件喂给 AI，再附上具体功能的提示词文件。
> 审计基准：2026-08-14，代码库 `desktopApp/` 当前状态。

---

## 1. 项目定位

**LectoForge 学习工作台**是一款 macOS 本地优先的学习闭环桌面应用。

核心方法论是一条四阶段学习闭环：

```
收集箱(Capture) → 康奈尔笔记(Note) → 记忆强化 → 费曼故事(Story)
                                    ├ 间隔重复 SM-2
                                    ├ 记忆宫殿 Loci
                                    └ 主动回忆（三轮闭卷）
```

产品特征：
- **数据主权**：全量数据存本机 SQLite，不上云、不需要账号、不需要登录
- **离线可用**：除 AI 增强（云端 LLM）外全部功能离线可用；AI 未配置时优雅降级
- **单用户**：后端硬编码 `CURRENT_USER = 1`，无鉴权体系
- **契约兼容**：接口与字段命名与 Web 端 `Wb*` 实体逐字段对齐

## 4. 后端三层架构（硬约束）

| 层 | 目录 | 只能做 | 严禁出现 |
|----|------|--------|----------|
| Route | `src/routes/` | 声明路径、HTTP 方法、参数 schema；绑定 Controller 函数 | `db.` / `drizzle-orm` / `axios` / `fetch(` / 任何业务分支 |
| Controller | `src/controllers/` | 解析 req、调用 Service、决定 HTTP 状态码 | 直接写 SQL / `drizzle-orm` 查询 |
| Service | `src/services/` | Drizzle 查询、文件 IO、axios 外呼、业务逻辑 | 引用 `FastifyRequest/Reply` |

**响应信封**：成功响应由 `index.ts` 的 `onSend` 钩子唯一负责包成 `{ code:200, data }`，Controller 直接 `return` 纯数据；SSE 是唯一例外（控制器直写 `reply.raw`）。

**better-sqlite3 同步事务**：`db.transaction((tx) => {...})` 回调**不得写成 async**，否则事务在首个 `await` 处提前提交。

## 6. UI 设计规范速查（红线）

### 6.1 全局禁止项

1. **禁止硬编码色值**：一律用 `var(--kb-*)` 或 Tailwind 令牌类（`primary`/`danger` 等）
2. **禁止散落魔法数字**：间距用 `--kb-space-*`（4/8/12/16/20/24/32px）
3. **禁止自造字号**：用 `--kb-fs-*` 阶梯
4. **禁止无状态反馈的可交互元素**：按钮/链接/菜单项必须有 hover/focus-visible/active 至少三态
5. **禁止脱离 Icon.vue 的图标**：用 `<Icon name="lucide名" />`
6. **禁止破坏响应式**：不写 `width:100vw`、不写撑破容器的 `nowrap`

### 6.2 间距令牌（4px 基线）

| Token | 值 | 用途 |
|-------|-----|------|
| `--kb-space-1` | 4px | 图标与文字微距 |
| `--kb-space-2` | 8px | 按钮内 gap、标签内边距 |
| `--kb-space-3` | 12px | 卡片内分组、列表项 |
| `--kb-space-4` | 16px | **默认区块间距**、卡片 padding |
| `--kb-space-5` | 20px | 区块标题↔内容 |
| `--kb-space-6` | 24px | 页面级留白 |
| `--kb-space-8` | 32px | 大段分隔 |

### 6.3 语义化布局类（优先使用）

```html
<div class="kb-stack">            <!-- 纵向 flex，gap:16px -->
<div class="kb-stack kb-stack-sm"> <!-- 纵向 gap:12px -->
<div class="kb-stack kb-stack-lg"> <!-- 纵向 gap:24px -->
<div class="kb-row">              <!-- 横向居中，gap:12px -->
<div class="kb-row-between">      <!-- 横向两端对齐 -->
<div class="kb-wrap">             <!-- flex-wrap 防溢出 -->
<div class="kb-min-0">            <!-- flex 子项 min-width:0 -->
<div class="kb-divider">          <!-- 1px 分隔线 -->
```

### 6.4 区域语义类

| 区域 | 类 | 效果 |
|------|-----|------|
| 顶栏 | `.kb-region-topbar` | 卡片色背景 + 底部 1px 边线 |
| 侧边栏 | `.kb-region-sidebar` | 略深侧栏色 + 右侧 1px 边线 |
| 主内容区 | `.kb-region-content` | 卡片→背景纵向微渐变 |
| 强调区 | `.kb-region-accent` | 主色+高光色径向渐变 |

### 6.5 字号阶梯（强制）

| 角色 | 类 | 字号 | 字重 |
|------|-----|------|------|
| Hero | `.kb-display` | 44px | 900 |
| H1 | `.kb-h1` | 32px | 700 |
| H2 | `.kb-h2` | 24px | 600 |
| H3/H4 | `.kb-h3`/`.kb-h4` | 20px | 600 |
| 正文 | `.kb-body` | 14px | 400 |
| 辅助 | `.kb-body-sm` | 13px | 400 |
| 标签 | `.kb-caption` | 12px | 500 |

### 6.6 交互反馈类（首选复用）

| 元素 | 类 | 已含反馈 |
|------|-----|---------|
| 通用按钮 | `.kb-btn` / `.kb-btn-primary` / `.kb-btn-danger` / `.kb-btn-sm` | hover变色+active下沉1px+disabled |
| 表单输入 | `.kb-input` | hover主色边+focus高亮环 |
| 下拉选择 | `.kb-select` / `.kb-select-sm` | hover/focus主色边 |
| 筛选分段 | `.kb-filter-btn` + `.kb-filter-group` | 默认灰+hover主色+.active主色软背景 |
| 自定义下拉 | `.kb-dropdown-trigger` + `.kb-dropdown-panel` + `.kb-dropdown-item` | trigger hover/focus+panel阴影 |
| 卡片表面 | `.kb-card` + `.kb-card-hover` | hover抬升2px+阴影+主色边 |

### 6.7 图标

```html
<Icon name="play" :size="18" />
<Icon name="bell" size="xl" />
```

| size | 像素 | 场景 |
|------|------|------|
| `xs` | 12 | 面包屑、tag |
| `sm` | 14 | 下拉箭头 |
| `md` | 16 | 导航、表单、按钮（默认） |
| `lg` | 18 | 移动端菜单 |
| `xl` | 20 | 顶栏操作 |
| `2xl` | 24 | 卡片、Hero |

图标用 `currentColor` 着色，禁止写死 `stroke="#333"`。

### 6.8 数字场景

统计、进度、计时、表格数字列必须加 `.tabular-nums`，保证等宽对齐。

## 7. vibecoding 通用约束

### 7.1 新增功能的标准流程

1. **数据层**：`schema.ts` 加表/字段 → `db/index.ts` 加幂等 DDL
2. **后端三层**：`types/` → `services/` → `controllers/` → `routes/` → `index.ts` 注册路由
3. **前端 API**：`src-ui/src/api/` 加模块封装
4. **前端 Store**（如需）：`src-ui/src/store/` 加 Pinia store
5. **前端视图**：`src-ui/src/views/` 加页面组件 → `router/index.ts` 加路由
6. **导航接入**（如需）：`DesktopTopNav.vue` 加导航项

### 7.2 命名约定

- 表名前缀 `wb_`，字段 `snake_case`，时间戳 `TEXT(ISO)`
- `user_id` 默认 1（单用户），保留以备多用户
- `tags` 字段统一为逗号分隔串
- 状态字段用字符串枚举（如 `status: 'inbox'|'today'|...`）
- 前端文件：`PascalCase.vue`，store 用 `useXxxStore`

### 7.3 AI Key 隔离

Key 只在 Node 侧车 / `ai-config.json`（`chmod 600`），永不下发渲染进程。

### 7.4 SM-2 不可被 AI 覆盖

复习排程是确定性算法，AI 只做「建卡 / 诊断 / 建议」，不改动 `nextReviewTime`。

### 7.5 提交前自检清单

- [ ] 颜色全部 `var(--kb-*)` 或 Tailwind 令牌类，无硬编码色值
- [ ] 间距全部 `--kb-space-*` 或语义布局类，无散落数字
- [ ] 字号落在阶梯，标题用 `.kb-h1~h4`/`.kb-display`
- [ ] 数字场景加了 `.tabular-nums`
- [ ] 每个可交互元素都有 hover / focus-visible / active 反馈
- [ ] 图标走 `<Icon name="lucide名">`，尺寸用语义 `size`
- [ ] Flex 子项长内容加了 `.kb-min-0`，无横向溢出
- [ ] 弹窗/面板有 `max-width`/`max-height` + 滚动兜底
- [ ] 不破坏深浅主题（所有可见色均引用令牌）
