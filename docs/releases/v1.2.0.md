## 这个版本做了什么

v1.2.0 是**首个正式打标的发布版本**。

由于 v1.1.0 之后持续快速迭代（项目此前未打 git tag），本版本聚合了 v1.1.0 之后的**全部工作**——
从最初的「学习闭环四模块」扩展为覆盖**记忆、规划、创作、AI、语音**的完整学习工具集。

一句话概括：**能用的功能全部到齐了，视觉与交互也做了一轮全站收敛。**

## 已知问题

本版本存在以下**已知且未修复**的问题，使用前请留意：

### 1. RAG 中文提问检索命中率低 ⚠️ 影响较大

知识库问答的**关键词降级路径**按空格与标点切分查询词。
**无空格的中文长问句会被当成一个超长词条**，导致检索命中率为 0，
最终回答「知识库中未找到相关内容」。

- **临时规避**：提问时用空格分隔关键词（如「间隔重复 复习间隔 怎么算」），
  或配置 embeddings 模型以走向量检索路径（向量检索优先，不受影响）。
- **修复方向**：引入中文分词。

### 2. 大规模知识库下内存占用偏高

向量检索当前为应用层余弦计算（全表拉入 JS）。约 5k 篇文档时 JS 堆峰值接近 490MB。

- **触发门槛**：embedding 行数 > ~1 万，或单次查询延迟 > 100ms，或堆峰值 > 300MB。
- **修复方向**：迁移到 `sqlite-vec` 做原生 KNN。

### 3. 离线语音开箱不可用

Whisper / Piper 模型体积过大，**不随仓库与安装包分发**。
语音输入与本地语音合成需先手动获取模型：

```bash
bash scripts/fetch-models.sh
bash scripts/build-whisper.sh
bash scripts/build-piper.sh
```

应用对此已做优雅降级（缺资源时给出明确提示，不会崩窗），但体验上是断链。

### 4. 模拟面试会话不持久化

面试会话状态存进程内存，**应用重启后丢失**，不做历史留存。

### 5. `/api/ai/associate` 关联项标题恒空

已知的字段大小写不一致缺陷（Service 读 `entity_type`，Drizzle 实返 `entityType`），
影响「AI 关联」功能的展示效果。计划在后续版本单独修复。

### 6. 分发未签名公证

构建产物为 ad-hoc 签名，**首次打开会被 Gatekeeper 拦截**。
按下方「安装方法」解除隔离即可，无需重新下载。

> 完整技术债分析见 [`docs/ARCHITECTURE.md` §11](../ARCHITECTURE.md#11-已知技术债)。

## 安装方法

### 1. 下载

从本页底部 **Assets** 下载对应的安装包：

- **Apple Silicon（M 系列）**：下载 arm64 版本
- **Intel**：下载 x64 版本

### 2. 解除隔离（首次必做）

当前产物未做 Apple Developer ID 签名与公证，首次打开会被 Gatekeeper 拦截。
把应用拖入「应用程序」后执行：

```bash
xattr -cr "/Applications/LectoForge 学习工作台.app"
open "/Applications/LectoForge 学习工作台.app"
```

### 3. 首次启动

会进入**新手引导**，可在此配置 AI API Key（也可跳过，之后在设置中心配置）。

### 4. 数据位置

所有数据保存在你自己的磁盘上：

| 位置 | 内容 |
|------|------|
| `~/Library/Application Support/com.lectoforge.desktop/` | SQLite 主库、AI 配置、上传件、日志 |
| 你自行选择的文件夹 | 文档库 vault（直接用 Markdown 原文件） |

**从 v1.1.0 及更早版本升级**：无需手动操作，应用启动时会自动检测并迁移历史数据
（幂等，且保留旧目录作为回滚安全网）。

## 从源码构建

```bash
git clone git@github.com:beiluoL/LectoForge.git
cd LectoForge

# ⚠️ Node 版本是硬约束：必须 24.16.0（ABI 137）
nvm install 24.16.0 && nvm use 24.16.0

npm --prefix src-api install
npm --prefix src-ui  install
npm install

npm run dev:all        # 纯前后端开发 → http://localhost:5173
# 或
bash scripts/prepare-bin.sh && npm run tauri dev   # 完整桌面应用
```

详见 [README](../../README.md) 与 [CONTRIBUTING](../../CONTRIBUTING.md)。
