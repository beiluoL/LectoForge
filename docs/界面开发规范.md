# 界面开发规范（UI Development Guidelines）

> **适用范围**：LectoForge 学习工作台桌面端（`src-ui/`）所有新增 / 修改界面。
> **核心约束**：整体 UI 风格不可改变。本规范**不是另起一套设计语言**，而是把项目已有的设计系统（`src-ui/src/style.css` 的 `--kb-*` 令牌、`tailwind.config.js` 色板、`src-ui/src/components/ui/Icon.vue` 图标组件、以及 `style.css` 内已定义的全局类）固化为**强制约束**。任何新界面、新组件、新页面都必须复用既有 token 与类，禁止引入风格漂移。
> **单一事实来源（Single Source of Truth）**：
> - 颜色 / 间距 / 圆角 / 阴影 / 字号 / 图标尺寸 → `style.css :root` 的 `--kb-*` 变量
> - Tailwind 调色板（`primary`/`success`/`warning`/`danger`/`highlight`/`gray`）必须与 `--kb-*` 一致，改主题先改 `style.css` 再同步 `tailwind.config.js`
> - 图标 → `Icon.vue`，禁止各页面手写重复 SVG 路径（除非该图标尚不在 `Icon.vue` 内，此时应**先补进 `Icon.vue`** 再使用）

---

## 0. 全局禁止项（红线，违反即不合格）

1. ❌ **硬编码色值**：禁止在 `style`、`class`、`inline style`、JS 中写死 `#3B6FE0` / `#FFF` / `rgb(...)` / `rgba(...)` 等具体颜色。一律改用 `var(--kb-*)` 或 Tailwind 的 `primary`/`danger` 等令牌类。
2. ❌ **散落魔法数字**：`gap-13px`、`padding: 18px`、`margin: 7px`、`width: 233px` 等。间距必须用 `--kb-space-*`（4/8/12/16/20/24/32px），尺寸用对应令牌。
3. ❌ **自造字号**：`font-size: 15px`、`text-[13.5px]`。字号必须落在 `--kb-fs-*` 阶梯（见 §2）。
4. ❌ **无状态反馈的可交互元素**：按钮 / 链接 / 菜单项 / 卡片点击区必须有 `hover` / `focus-visible` / `active` 至少三态之一（见 §3）。
5. ❌ **脱离 `Icon.vue` 的图标**：不得在模板里直接写 `<svg viewBox="0 0 24 24">` 画项目已收录的图标；新增图标先补进 `Icon.vue`。
6. ❌ **两套令牌漂移**：`tailwind.config.js` 的 `primary-500` 必须等于 `#3B6FE0`，与 `--kb-primary` 永远一致。
7. ❌ **破坏响应式**：出现 `width: 100vw`、`white-space: nowrap` 撑破容器、`overflow-x: scroll` 内容被裁剪却无横向滚动方案等。

## 1. 布局与间距（Layout & Spacing）

### 1.1 间距令牌（4px 基线网格，唯一来源 `--kb-space-*`）

| Token | 值 | 典型用途 |
|---|---|---|
| `--kb-space-1` | 4px | 图标与文字微距、分隔线两侧 |
| `--kb-space-2` | 8px | 导航图标↔文字、按钮内 gap、标签内边距 |
| `--kb-space-3` | 12px | 卡片内分组、侧栏图标↔文字、列表项垂直距 |
| `--kb-space-4` | 16px | **默认区块间距**、表单字段距、卡片 padding |
| `--kb-space-5` | 20px | 区块标题↔内容 |
| `--kb-space-6` | 24px | 页面级留白、大卡片 padding |
| `--kb-space-8` | 32px | 页面顶部留白、大段分隔 |

> 在 Tailwind 中可直接用 `gap-4`（=16px）等，但**语义化布局优先用下面的组合类**。

### 1.2 语义化布局组合类（优先使用，保证对齐一致）

```html
<div class="kb-stack">            <!-- 纵向 flex，gap:16px -->
<div class="kb-stack kb-stack-sm"> <!-- 纵向 gap:12px -->
<div class="kb-stack kb-stack-lg"> <!-- 纵向 gap:24px -->
<div class="kb-row">              <!-- 横向对齐居中，gap:12px -->
<div class="kb-row-between">      <!-- 横向两端对齐，gap:12px -->
<div class="kb-wrap">             <!-- flex-wrap:wrap，防溢出换行 -->
<div class="kb-min-0">            <!-- flex 子项 min-width:0，允许收缩防撑破 -->
<div class="kb-divider">          <!-- 1px 分隔线，margin 16px 0 -->
```

### 1.3 区域语义类（建立视觉层次，禁止自造背景）

| 区域 | 类 | 效果 |
|---|---|---|
| 顶栏 | `.kb-region-topbar` | 卡片色背景 + 底部 1px 边线 |
| 侧边栏 | `.kb-region-sidebar` | 略深侧栏色 + 右侧 1px 边线 |
| 主内容区 | `.kb-region-content` | 卡片→背景纵向微渐变，制造纵深 |
| 强调区（Hero/AI） | `.kb-region-accent` | 主色+高光色径向渐变氛围 |

### 1.4 内容容器与对齐规则

- 一级页面内容统一包在 `max-w-7xl`（或已有 `DesktopTopNav` 下的内容容器）内，左右自动留白，禁止全宽铺满正文。
- 页面标题区：`<h1 class="kb-h1">` 或 `<div class="kb-display">`（Hero），下方接 `kb-stack` 内容。
- 卡片网格用 `grid` + `gap-[var(--kb-space-4)]`；响应式列数用 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`。
- 表单：标签用 `.kb-label`，控件用 `.kb-input` / `.kb-select`，字段间距用 `.kb-stack` 或 `space-y-[var(--kb-space-4)]`，禁止逐字段手写 `margin-bottom`。

## 2. 字体与排版（Typography）

### 2.1 字体家族（仅这四套，禁止引入新字体）

| 用途 | 变量 | 渲染类 |
|---|---|---|
| 正文 / UI 文本 | `--font-sans`（Noto Sans SC） | 默认 |
| 展示标题 H1/H2/H3 | `--font-serif`（Noto Serif SC，杂志感） | `.kb-h1`/`.kb-h2`/`.kb-h3` |
| Hero 大标题 | `--font-display`（Noto Serif SC 900） | `.kb-display` |
| 代码 / 数字列 | `--font-mono`（JetBrains Mono，等宽连字） | `code`/`pre`/`.tabular-nums` |

### 2.2 字号阶梯（强制，禁止离梯字号）

| 角色 | 类 | 字号 | 行高 | 字重 |
|---|---|---|---|---|
| Hero | `.kb-display` | 44px | 1.15 | 900 |
| H1 | `.kb-h1` | 32px | 1.25 | 700 |
| H2 | `.kb-h2` | 24px | 1.30 | 600 |
| H3 | `.kb-h3` | 20px | 1.35 | 600 |
| H4 / 卡片标题 | `.kb-h4` | 20px | 1.40 | 600 |
| 正文大 | `.kb-body` | 16px | 1.60 | 400 |
| 正文默认 | `.kb-body` | 14px | 1.60 | 400 |
| 辅助正文 | `.kb-body-sm` | 13px | 1.50 | 400 |
| 标签/说明 | `.kb-caption` | 12px | 1.50 | 500（大写+字距） |
| 角标/时间 | — | 11px | 1.40 | 500 |

> 对应原始令牌：`--kb-fs-h1`…`--kb-fs-xs`、`--kb-fw-*`、`--kb-lh-*`。需要单独指定时用 `var(--kb-fs-body-md)` 等，**不要写死 px**。

### 2.3 排版规则

- 标题层级分明：页面只应有一个 H1/Hero；H2/H3 用于区块；同一屏内字号差不小于 4px。
- 长标题用 `text-wrap: balance`（已内置在 `.kb-h1~h3`）避免孤行。
- **数字场景**（统计、进度、计时、表格数字列）必须加 `.tabular-nums`，保证等宽对齐、跳动不抖动（番茄钟菜单栏计时尤其重要）。
- 正文 `line-height` 1.6，辅助文字 1.5；禁止 1.2 以下正文行高。
- 全局已开启 `font-optical-sizing: auto` 与 `-webkit-font-smoothing: antialiased`，不要关闭。

## 3. 交互反馈（Interactive Feedback）

**原则**：每一个可交互元素都必须给出明确的操作响应——用户要能感知「这个东西可以点」「我现在悬停在哪」「我按下了」「我聚焦到了」。

### 3.1 复用内置反馈类（首选，零成本合规）

| 元素 | 使用类 | 已含反馈 |
|---|---|---|
| 通用按钮 | `.kb-btn` / `.kb-btn-primary` / `.kb-btn-danger` / `.kb-btn-sm` | hover 变色+主色边、`:active` 下沉 1px、disabled 半透明+`not-allowed` |
| 主/次按钮 | `.btn-primary` / `.btn-secondary` | hover 透明度、active 下沉+透明度 |
| 表单输入 | `.kb-input`（含 `textarea`/`select` 形态） | hover 主色边、`focus` 主色高亮环、disabled 置灰 |
| 下拉选择 | `.kb-select` / `.kb-select-sm` | hover/focus 主色边+高亮环、disabled |
| 筛选/分段 | `.kb-filter-btn` + `.kb-filter-group` | 默认灰、hover 主色、`.active` 主色软背景、disabled |
| 自定义下拉 | `.kb-dropdown-trigger` + `.kb-dropdown-panel` + `.kb-dropdown-item` | trigger hover/focus、panel 阴影、item hover/focused/selected 态 |
| 卡片表面 | `.kb-card` + `.kb-card-hover` | hover 抬升 2px + 阴影 + 主色边 |

### 3.2 焦点反馈（可访问性硬性要求）

- 键盘可达元素必须有可见焦点环：**不要** `outline:none` 后不给替代。全局已对 `a/button/[tabindex]/[role=button]` 设 `:focus-visible` 描边；自定义控件用 `--kb-focus-ring`（`0 0 0 3px rgba(59,111,224,0.28)`）或 `box-shadow: 0 0 0 3px rgba(59,111,224,0.1)`。
- 输入框聚焦：主色边 + 主色软光环（`.kb-input:focus` 已实现）。

### 3.3 按下 / 点击反馈

- 所有按钮类已统一 `:active { transform: translateY(var(--kb-press-y)); }`（1px 下沉），**不要移除**。
- 主按钮 active 额外 `opacity:0.85`，给予明确按压感。

### 3.4 禁用态

- `:disabled` 元素统一 `opacity` 降低 + `cursor: not-allowed`，且**不改变布局尺寸**（防抖动用 `transform` 而非 `margin`）。

### 3.5 禁止

- ❌ 纯 `div` 当按钮却无 `cursor:pointer`、无 hover、无焦点态。
- ❌ `:hover` 仅改背景却不区分深浅主题（必须用 `var(--kb-*)` 才能深浅自动响应）。
- ❌ 过渡时长乱写；统一 `transition: ... 0.15s ease` / `0.2s ease`（全局 `.transition-base` 为 `0.2s`）。

## 4. 图标与图形（Icons & Graphics）

### 4.1 唯一入口：`Icon.vue`

所有图标通过 `<Icon :name="..." />` 渲染，`name` 传 **lucide 图标名**（PascalCase 或 kebab-case 均可，如 `MapPin` / `map-pin`）。组件内部是 5 路互斥渲染链（图片 → iconfont → SVG 代码 → lucide → 手写兜底 SVG），**不要绕过它直接写 `<svg>`**。

### 4.2 图标尺寸令牌（禁止任意 px）

| size 值 | 像素 | 场景 |
|---|---|---|
| `xxs` | 10 | 列表点、角标 |
| `xs` | 12 | 面包屑、tag |
| `sm` | 14 | 下拉箭头、辅助 |
| `md`（默认） | 16 | 导航、表单、按钮 |
| `lg` | 18 | 移动端菜单 |
| `xl` | 20 | 顶栏操作、Logo |
| `2xl` | 24 | 卡片、Hero |
| `3xl` | 32 | 空状态、插画 |

```html
<Icon name="play" :size="18" />   <!-- 用语义 size，不用 :size="18" 裸数字亦可，但优先语义词 -->
<Icon name="bell" size="xl" />
```

### 4.3 图标视觉约定

- **描边风格统一**：手写/SVG 兜底图标一律 `stroke="currentColor"`、`stroke-width="2"`、`fill="none"`（见 `Icon.vue` 手写 SVG 段），圆角 `stroke-linecap="round"`。
- **颜色跟随文字**：图标用 `currentColor`，通过父级 `color` 或 `color` prop 着色，**禁止写死 `stroke="#333"`**。需要主色图标就放在主色文字容器里，或用 `color="var(--kb-primary)"`。
- **可访问性**：装饰性图标 `decorative`（默认 `true`，对屏幕阅读器隐藏）；若图标承载含义（如「删除」按钮只有图标），必须 `:decorative="false" :aria-label="'删除'"`。

### 4.4 图形 / 图表 / 插画

- 内联 SVG / Canvas / `chart.js` + `vue-chartjs` 等自定义图形：配色**必须引用 `var(--kb-*)`**（主色、成功、危险、高光等），禁止硬编码，确保深浅主题切换时同步。
- 所有 `img`/`svg`/`canvas` 已全局 `max-width:100%`，自定义图形不要再设死宽导致横向溢出。
- 高光时刻（成就/打卡/AI 推荐）统一用 `.highlight-badge` / `.highlight-text` / `.highlight-glow` / `highlight-pulse` 工具类与 `--kb-highlight`（#FF6B35），保持 80/20 主辅关系，**不大面积铺高光色**。

## 5. 响应式适配（Responsive）

### 5.1 防溢出（全局已兜底，但组件仍需配合）

- 全局已设 `img, video, canvas, svg { max-width: 100% }`，自定义容器不要再覆盖为 `width:100vw` 或固定超大宽。
- **Flex 子项防撑破**：任何 `flex` 容器内可能出现长文本/长 URL 的子项，加 `.kb-min-0`（= `min-width:0`），否则 flex 默认 `min-width:auto` 会被内容撑破导致横向滚动。
- 长文本用 `.text-ellipsis`（单行）或 `.text-ellipsis-2`（两行），禁止无截断地铺满。

### 5.2 布局自适应

- 优先 `flex-wrap`（`.kb-wrap`）+ `gap` 而非固定多列；网格用 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3` 递进。
- 顶栏/侧栏在窄宽下应可收起或用图标（已有 `lg=18px` 移动端菜单尺寸约定）；不要求支持手机，但**桌面端窗口缩到 ~1000px 不应错乱溢出**。
- 弹窗/下拉面板设 `max-width`（如 `.kb-dropdown-panel.kb-dropdown-wide` 的 `max-width:360px`）并 `max-height + overflow-y:auto`，防止选项过多溢出视口。

### 5.3 字体与 DPI

- 全局已设 `-webkit-text-size-adjust:100%` 与 `text-size-adjust:100%`，禁止浏览器在横屏/小屏自动放大字号——**保持设计稿字号阶梯稳定**。
- 使用 `px` 令牌（非 `pt`/`em` 混合），高 DPI 屏下由系统自动按 devicePixelRatio 渲染，无需手动 `@2x` 处理。
- 图标尺寸用 `var(--kb-icon-*)`，SVG 用 `currentColor`，在高 DPI 下天然清晰。

### 5.4 动效与无障碍

- 全局已处理 `prefers-reduced-motion: reduce`（用户开启「减少动效」时禁用所有过渡/动画）。**新增动效不要绕过此守护**（即不要写 `!important` 强制动画）。
- 入场动效复用 `.reveal-item`（父加 `.reveal-stagger` 或子项内联 `--reveal-index`），不要各页面自造 `@keyframes`。

## 6. 提交前自检清单（Code Review 门禁）

新增/修改界面时，逐项确认：

- [ ] 颜色全部 `var(--kb-*)` 或 Tailwind 令牌类，无硬编码色值
- [ ] 间距全部 `--kb-space-*` 或语义布局类，无散落数字
- [ ] 字号落在 §2.2 阶梯，标题用 `.kb-h1~h4`/`.kb-display`
- [ ] 数字场景加了 `.tabular-nums`
- [ ] 每个可交互元素都有 hover / focus-visible / active 反馈（优先复用内置类）
- [ ] 图标走 `<Icon name="lucide名">`，尺寸用语义 `size`，无手写重复 SVG
- [ ] 图标 `stroke="currentColor"`、`stroke-width="2"`，颜色跟随文字
- [ ] Flex 子项长内容加了 `.kb-min-0`，无横向溢出
- [ ] 弹窗/面板有 `max-width`/`max-height` + 滚动兜底
- [ ] 改动主题相关色值时，`style.css` 与 `tailwind.config.js` 同步
- [ ] 不破坏深浅主题（所有可见色均引用令牌，深色 `data-theme='dark'` 自动响应）
